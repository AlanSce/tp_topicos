Para ejecutar el juego Tetris correctamente, primero se debe descargar e instalar Code::Blocks desde el sitio oficial https://www.codeblocks.org/downloads/. Es importante descargar específicamente la versión que ya incluye MinGW/GCC, ya que el proyecto está desarrollado en lenguaje C y necesita el compilador GCC para poder compilar. Durante la instalación se pueden dejar todas las opciones por defecto hasta finalizar.

Luego de instalar Code::Blocks, descargar la biblioteca GBT v2026.1C.01 utilizada por el proyecto. La carpeta de la biblioteca debe colocarse dentro de la carpeta "lib" del proyecto respetando exactamente la estructura de directorios original. La estructura esperada es que dentro de la carpeta principal del proyecto exista una carpeta llamada "lib", y dentro de ella la carpeta "GBT_v2026.1C.01" con sus subcarpetas "include", "lib", "bin" y demás archivos correspondientes.

Con todos los archivos ya ubicados correctamente, abrir Code::Blocks desde el acceso directo del escritorio o desde el menú inicio. Una vez abierto el programa, seleccionar la opción "File -> Open" y buscar dentro de la carpeta del proyecto el archivo llamado "TETRIS.cbp", que corresponde al proyecto principal de Code::Blocks. Al abrirlo, el entorno cargará automáticamente todos los archivos fuente como main.c, Funciones.c y Funciones.h.

Después de abrir el proyecto, verificar que las rutas de la biblioteca estén correctamente configuradas. Para hacerlo, ir a "Project -> Build Options". Dentro de la sección "Search Directories -> Compiler" debe existir la ruta hacia "lib/GBT_v2026.1C.01/include". Luego, dentro de "Search Directories -> Linker" debe existir la ruta hacia "lib/GBT_v2026.1C.01/lib".

Una vez verificado todo, abrir el archivo "main.c" desde el panel izquierdo de archivos para comprobar que el proyecto cargó correctamente. Finalmente, presionar la tecla F9 o seleccionar la opción "Build -> Run". Code::Blocks comenzará automáticamente el proceso de compilación. Si no existen errores de configuración ni archivos faltantes, se abrirá la ventana del juego y el entorno quedará listo para jugar Tetris.

Una vez dentro del programa (pantalla tipo CMD), mover con las flechas del teclado a la pantalla de instrucciones para verificar controles. Luego de cada partida se generara una Linea en un archivo nuevo 'estadisticas_jugador.txt' donde se podra ver el historial de puntajes.
